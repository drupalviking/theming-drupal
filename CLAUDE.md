# Theming Drupal

An open (CC BY-SA 4.0) book about building Drupal themes, the companion to the site-building book in `../developing-open-sourced-web-software-with-drupal`. The reader gives Book 1's Lens & Trail sites themes of their own.

- Read `README.md` (layout, commands, status) and `PROJECT-LOG.md` (decisions, open items, backlog) first.
- For any work on a chapter, use the `write-chapter` skill (`.claude/skills/write-chapter/SKILL.md`).
- Edit `manuscript/`, never `book/` (generated by `python3 tools/build.py`; commit both). Never type code into the manuscript: include it from tested files under `code/`.
- One chapter at a time: ask the author many questions about scope before drafting (they asked for it), and wait for their review before starting the next chapter.
- The test sites are DDEV projects outside this repository: `tools/setup.sh` makes them, `tools/use-step.sh <chapter> <step>` puts a theme step on them.
